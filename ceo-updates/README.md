# CEO de IAs — canal de actualizaciones

Canal temporal y aislado para transportar actualizaciones de CEO de IAs sin modificar `main` de Radar.

Manifest estable: `ceo-updates/manifest.json`.

DEV21 usa un bootstrap delta DEV20→DEV21 verificado por hashes. La versión previa se copia y conserva; la activación requiere confirmación humana y no existe autopromoción.

A partir de DEV21, CEO trae este canal preconfigurado y las siguientes actualizaciones se gestionan desde la propia aplicación.
